What's New in v1.1

TV Remote UX & D-Pad Navigation Hardening

  • Safe Back at Root (/): Pressing Back at the top-level directory now displays a lightweight "Disconnect from server?" confirmation modal instead of accidentally killing the session and forcing a re-pair.
  • Direct Home Screen Exit: Aligned with official Google TV App Quality Guidelines—pressing Back from the disconnected start screen exits directly to the Android TV launcher without redundant exit popups.
  • Per-Folder Focus Memory: Navigating up to parent directories or returning from the video player restores scroll position and automatically re-focuses the exact folder or media card you just left.
  • Top Bar Focus Path: Pressing D-Pad UP from row 0 of both the 4-column Grid and List view cleanly transfers remote focus to the Top Bar controls without getting stuck.

LibVLC Media Engine & Debounced Seeking

  • LibVLC 3.6.2 Engine: Complete native decoding with hardware acceleration (mediacodec_ndk, mediacodec_jni) for 10-bit HEVC, Matroska MKVs with cue points, and complex ASS/SSA subtitles.
  • Hold-to-Accelerate Seeking: Seeking Left/Right updates a live visual timestamp preview instantly, escalating step sizes (10s → 30s → 60s) while held, and commits to LibVLC after a 400ms debounce to eliminate LAN/SMB buffering choke.
  • Live Aspect Ratio Switcher: Replaced redundant on-screen exit buttons with a multi-ratio toggle (Fit, 16:9, 4:3, 2.35:1) directly in the HUD control bar.
  • Folder Playlist Navigation: Added [⏮ Prev] and [⏭ Next] buttons and wired remote media keys (KEYCODE_MEDIA_NEXT / PREVIOUS) to skip sequentially through files in the current folder.
  • Smart HUD Auto-Hide: Pauses the 5-second auto-hide timer while video playback is paused, and maintains subtle ambient HUD visibility during audio-only playback (.mp3, .flac, .wav) to protect OLED panels from pure black screens.
  • Debounced Multi-Track Switching: Smooth track switching for multi-audio streams (e.g. Hindi 5.1 / English Atmos) and subtitles without audio dropouts or player freezing.

Long-Press Media Quick Actions Modal

  • Remote Menu & Long-Press OK: Long-pressing Center/OK or pressing remote MENU / INFO on any media card opens a dedicated action sheet.
  • Instant Action Shortcuts: Quickly select Resume from Timestamp, Play from Beginning (bypasses Smart Resume), Clear Saved Progress, or view full File Information.

TvTheme Design System & Anti-Bloom Upgrades

  • Neutral Glass Card Borders: Changed unfocused borders from faint cyan to neutral 10% translucent white (#1AFFFFFF), removing the grid "wireframe" look.
  • High-Visibility Ice-White Focus Core: Active focus border uses a 2.5dp crisp ice-white core (#F1F5F9) with an electric cyan halo glow, ensuring cards pop unmistakably over dark or vibrant movie posters.
  • Anti-Halation & Contrast Tuning: Softened primary text to #F1F5F9 to eliminate OLED/HDR bloom in dark environments; raised muted text to #7D8FA6 for WCAG AA compliance (5.5:1); unified brand electric blue to #1A64E6 (>4.9:1).
  • Wallpaper Bleed Guard: Raised card inner container opacity to 72% (#B80A0F1D) and introduced an atmospheric backdrop scrim, preventing bright orange and magenta gradients from bleeding into metadata on dynamic themes.
  • Standardized Status Tokens: Added comprehensive LanStreamError* and LanStreamWarning* design tokens for connection and timeout notifications.

Nova Video Player-Style Directory Browsing & Resume

  • Folders-First Sorting: Directories always appear at the top, followed by media files sorted alphabetically (A-Z).
  • 4-Column Poster Grid & Detailed List Views: High-density cards with category banners and full-width list rows with persistent layout memory across relaunches.
  • Smart Resume Playback: Remembers exact playback timestamps; automatically prompts interactive [Resume] / [Start from Beginning] modals and displays cyan progress bars on partially watched media.

Optimized R8 Single-DEX Compilation & Performance

  • Single-DEX Packaging: Deep R8 full-mode tree-shaking compresses the entire Android TV application into a single classes.dex file (~42k methods), comfortably below the 64K multidex threshold.
  • Zero Multidex Latency: Eliminates runtime multidex extraction and class verification overhead, ensuring instant cold-start boot times on smart TVs.
  • Resource & Log Stripping: Stripped unused resources and bytecode debug logging, keeping the TV APK compact at ~86.5 MB.
  • AOT ART Speed Compilation: Pre-compiled natively on-device (cmd package compile -m speed) for fluid 60fps Leanback UI animations.
