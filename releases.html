What's New in v1.1

LibVLC Media Engine Integration

  • Migrated Android TV media playback from ExoPlayer to native LibVLC 3.6.2 with hardware acceleration (mediacodec_ndk, mediacodec_jni).
  • Full native decoding for complex 10-bit HEVC (H.265), high-bitrate Matroska MKVs with VBR/Cues, and stylized ASS/SSA subtitles.
  • Multi-track audio stream switching (e.g. Hindi 5.1, English Atmos, regional tracks) directly via TV remote control.
  • Integrated remote button actions: D-Pad Left/Right 10-second fast seek, Center/OK Play-Pause, Speed toggle (0.5x to 2.0x), and track cycling.

Nova Video Player-Style Directory Browsing

  • Folders-First Sorting: Directories always appear at the top, followed by media files sorted alphabetically (A-Z).
  • 4-Column Poster Grid View: High-density visual cards with category gradient banners, extension badges, and remote focus scaling.
  • Detailed List View: Full-width rows with complete file names, metadata tags, and quick-action play buttons.
  • Persistent Layout Toggle: Switch between Grid and List view with a single click; preference is remembered across app relaunches.

Smart Resume Playback with D-Pad Prompt

  • Resume Playback Dialog: Clicking partially watched videos prompts an interactive TV dialog with [Resume from XX:XX] and [Start from Beginning].
  • Watch Progress Indicators: Video poster cards and list rows display cyan progress bars and saved timestamp chips.
  • Auto-Save on Exit & Pause: Playback timestamps automatically save when pausing, pressing Back, or backgrounding the TV app.
  • Auto-Clear on Completion: Automatically clears saved timestamps once videos are watched past 95% completion.

Optimized R8 Single-DEX Compilation & Performance

  • Single-DEX Packaging: Deep R8 full-mode tree-shaking compresses the entire Android TV application into a single classes.dex file (~42k methods), comfortably below the 64K multidex threshold.
  • Zero Multidex Latency: Eliminates runtime multidex extraction and class verification overhead, ensuring instant cold-start boot times on smart TVs.
  • Resource Shrinking: Stripped unused resources and dead layouts, reducing TV APK download size to ~86.5 MB.
  • Bytecode Log Stripping: Stripped verbose and debug Log invocations at R8 compilation to reduce CPU overhead and garbage collection pauses on quad-core TV processors.
  • AOT ART Speed Compilation: Pre-compiled natively on-device (cmd package compile -m speed) for fluid 60fps Leanback UI animations.
